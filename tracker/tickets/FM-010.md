## Context
Five service repos each need the same pipeline: build, unit test, integration
test, report. Writing it five times guarantees five divergent pipelines.

GitHub lets a repo call a reusable workflow from another repo in the same org.
Verify that works for this plan and these repo visibilities **before** building
on it — if org-level sharing is unavailable, either keep `platform` public (it
holds docs only, no secrets) or fall back to a copied workflow plus a documented
recipe. Record whichever you choose.

This is last in sprint 0 on purpose: there is no point wiring CI before there is
a green integration test for it to run.

## Acceptance criteria
- [ ] `platform/.github/workflows/java-service.yml` defined with `workflow_call`
- [ ] Steps: checkout, set up JDK 21 with Gradle cache, `./gradlew build`, `./gradlew integrationTest`
- [ ] `integrationTest` is its own explicit step — see the decision recorded in FM-002
- [ ] Test results published as a job summary, visible without downloading artifacts
- [ ] Build fails the job on test failure — confirmed by pushing a deliberately broken test, then reverting
- [ ] `expense-service-backend` calls it from its own workflow and goes green on a real push
- [ ] Decision on reusable-vs-copied recorded in this ticket or an ADR

## Learning notes
Testcontainers works on GitHub-hosted runners because Docker is available — no
service containers needed in the workflow. The Gradle cache is what takes CI
from four minutes to ninety seconds; set it up now, while the build is small
enough that you can see the difference.

The `integrationTest` step is load-bearing. FM-002 deliberately kept it out of
`check` so `./gradlew build` stays container-free, which means **nothing** runs
the integration suite unless CI calls it by name. A pipeline that goes green
while the integration tests sit unexecuted is worse than no pipeline, because it
is trusted. Do not remove that step to speed up CI.

Push a broken test deliberately. A CI pipeline nobody has watched fail is not a
pipeline, it is decoration.
